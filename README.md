# Salam Offer Lens

Salam Offer Lens is an offline command-line auditor for public work and bounty
offers, built with the [Salam Programming Language](https://github.com/SalamLang/Salam).

It turns a small pipe-delimited offer record into an evidence-oriented report.
The report distinguishes stated facts from missing terms, flags spend and
funding risks, and names the next read-only check instead of treating a listing
as permission to act.

The project is under active development. Run instructions and worked examples
will be added as each verified module lands.
